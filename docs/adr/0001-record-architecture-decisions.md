# ADR 0001 - Record Architecture Decisions

## Status
Accepted

## Context
We need a standard format to record and track architectural choices, context, and implications as the **CampusCare** platform scales.

## Decision
We will use Architecture Decision Records (ADRs) placed under the `docs/adr/` folder. All documents will follow a basic layout containing Status, Context, Decision, and Consequences.

## Consequences
- Developers and AI agents can review past decisions to avoid reinventing patterns.
- Keeps design history transparent.
