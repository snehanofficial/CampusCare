# Reports Feature Module

This is the React frontend feature module for reports.

## Structure
- `components/` contains UI views specific to this feature.
- `hooks/` contains custom hooks.
- `pages/` contains route-level screen components.
- `services/` handles API fetching using React Query or Axios templates.
- `types/` contains client-side structures.
- `schemas/` contains form validation schemas.
- `store/` handles feature state if required.
