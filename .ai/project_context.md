# Project Context - CampusCare

CampusCare is a Mobile-First IT Service Management & Campus Help Desk application designed to optimize support ticketing, asset maintenance, spare parts tracking, and SLA monitoring.

## Stakeholder Targets
- **Students & Faculty:** Submit issues, track request timelines, scan QR tags on broken appliances to report issues.
- **Technicians:** Claims tickets, logs work hours, consumptions of spare parts, updates assets status.
- **Dept Administrators:** Manages queues, monitors SLA counts, reviews audits.
